# کد برنامه

کد پیاده‌سازی سامانه در این پوشه قرار خواهد گرفت. در وضعیت فعلی، مستندات طراحی و دیتابیس نمونه آماده‌اند و هنوز برنامه یا رابط کاربری نوشته نشده است.

زبان و چارچوب برنامه‌نویسی بعداً انتخاب می‌شوند. در اجرای برنامه می‌توان دیتابیس عملیاتی را در پوشه محلی runtime در ریشه پروژه ساخت؛ این پوشه در .gitignore قرار دارد. فایل database/food_order.db نمونه ثابت برای ارائه و بررسی ساختار است.
