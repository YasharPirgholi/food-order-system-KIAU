# سامانه سفارش غذا

سامانه‌ای برای سفارش غذا از چند رستوران، با قابلیت مشاهده منو، مدیریت سبد خرید، ثبت سفارش، پرداخت شبیه‌سازی‌شده و پیگیری وضعیت سفارش.

## دامنه و نقش‌ها

مشتری غذا انتخاب می‌کند، اطلاعات تحویل را وارد می‌کند و سفارش خود را پرداخت و پیگیری می‌کند. مسئول رستوران منو و مراحل آماده‌سازی، ارسال و تحویل سفارش‌های رستوران خود را مدیریت می‌کند. مدیر سیستم به مدیریت کاربران، رستوران‌ها و گزارش سفارش‌ها دسترسی دارد.

هر سفارش متعلق به یک رستوران است. هزینه ارسال برای هر رستوران ثابت و واحد همه مبلغ‌ها تومان است. لغو سفارش فقط پیش از پرداخت موفق مجاز است. پرداخت بانکی واقعی، حساب مستقل پیک و بازپرداخت در دامنه این نسخه قرار ندارند.

## وضعیت توسعه

سند نیازمندی‌ها، نمودارهای مفهومی و دیتابیس SQLite شامل شش جدول، داده نمونه و پرس‌وجوهای مرتبط آماده‌اند. برنامه و رابط کاربری هنوز پیاده‌سازی نشده‌اند.

## اجرای دیتابیس

دیتابیس به SQLite نسخه 3.37 یا جدیدتر نیاز دارد. فایل [food_order.db](database/food_order.db) شامل ساختار و داده نمونه است و با [DB Browser for SQLite](https://sqlitebrowser.org/) باز می‌شود. پرس‌وجوهای آماده در [queries.sql](database/queries.sql) قرار دارند.

برای بازسازی، در یک دیتابیس خالی ابتدا [schema.sql](database/schema.sql) و سپس [seed.sql](database/seed.sql) اجرا شوند. در هر اتصال، کنترل کلیدهای خارجی با `PRAGMA foreign_keys = ON;` فعال شود. جزئیات جدول‌ها، قواعد و حساب‌های نمونه در مستند دیتابیس آمده‌اند.
