# سامانه سفارش غذا

پروژه درس آزمایشگاه مهندسی نرم‌افزار در مقطع کارشناسی کامپیوتر. هدف، طراحی و پیاده‌سازی یک سامانه سفارش غذا در سطح متوسط دانشجویی است.

## دامنه پروژه

سه نقش مشتری، مسئول رستوران و مدیر سیستم در نظر گرفته شده‌اند. مشتری غذا انتخاب می‌کند، سفارش ثبت می‌کند و پرداخت آزمایشی انجام می‌دهد. مسئول رستوران منو و مراحل آماده‌سازی، ارسال و تحویل سفارش را مدیریت می‌کند. مدیر سیستم کاربران، رستوران‌ها و گزارش‌های ساده را مدیریت می‌کند.

در این نسخه، پرداخت بانکی واقعی، حساب مستقل پیک و بازپرداخت در دامنه پروژه قرار ندارند.

## اجرای بخش آماده دیتابیس

1. [DB Browser for SQLite](https://sqlitebrowser.org/) را نصب و اجرا کنید. موتور SQLite باید نسخه 3.37 یا جدیدتر باشد.
2. با Open Database فایل [database/food_order.db](database/food_order.db) را باز کنید.
3. در Browse Data داده‌ها را ببینید.
4. در Execute SQL پرس‌وجوهای [queries.sql](database/queries.sql) را اجرا کنید.

برای ساخت دیتابیس خالی از ابتدا، ابتدا [schema.sql](database/schema.sql) و سپس [seed.sql](database/seed.sql) را اجرا کنید. فایل آماده قبلاً شامل ساختار و داده نمونه است.

برای این مرحله، سبد خرید در Session برنامه مدل شده است و پس از تأیید به orders و order_items منتقل می‌شود. همه مبلغ‌ها تومان‌اند و نتیجه هر تلاش پرداخت ثبت می‌شود. جزئیات قواعد و مسئولیت کد برنامه در راهنمای دیتابیس توضیح داده شده‌اند.
